## 二、双语版差异的显著标识（新增）

**背景**：zh / en 两版由 `buildEdition` **各自独立选稿**，头条、栏目、简讯、副刊均不同源
（实测当日 zh 头条「外交部…高市早苗涉台」，en 头条「Nato jets down drone…」），
但页面上**没有任何说明**，读者极易误以为二者是同一份报纸的两个语言版本而互相参校。

**实现**：新增 `src/components/EditionNotice.astro`，置于**报头之下、栏目条之上**（报纸「启事」的惯常位置）。
- 三段结构：套红标签「读者须知 / A Note to Readers」+**套红加粗关键句**
  （「中、英两版内容并不相同，亦非逐篇互译」）+ 说明正文与切换链接。
- 样式 §3c：纸暗底 + 上下细线夹持，正文 `max-width: 62ch` 限宽。
- 挂载点：`FrontPage.astro` 与 `Archive.astro` —— 覆盖全部 6 个入口页。
- 打印态隐藏切换链接（纸上点不动）。

## 三、英文版报头：刊名层级镜像反转 + 字体设计

**用户要求**：英文版「大标题是英文、小标题才是中文，与中文版恰恰相反」，且需为字体做合理设计。

**实现**（`Masthead.astro` + CSS §3b）——两版互为镜像：

| 位置 | zh 版 | en 版 |
|---|---|---|
| **大字位**（h1） | 每日新報 · Noto Serif SC 900 · 88px · 字距 .22em · 双钩描边 | The Daily News · Playfair Display **900** · **72px** · 字距 **.02em** · **无描边** |
| **小字位** | The Daily News · IM Fell 斜体套红 | 每日新報 · Noto Serif SC 700 套红 · 字距 .3em |

**为何不能沿用中文刊名那套处理**（三项各有物理原因，已写入 CSS 注释）：
1. `.22em` 字距——汉字等宽，拉开是端庄；拉丁小写比例字宽参差，拉开成「字间漏风」；
2. 双钩描边——为补宋体细笔画墨量而设；Playfair 横竖对比本强，再描边衬线会糊成一团；
3. 88px——「The Daily News」14 字符横向占位约为「每日新報」4 字的 1.6 倍，沿用会挤掉两侧期数/日期栏。

**新增 Playfair Display 900 字重**：中文刊名是宋体 900，拉丁若停在 700 同一行会明显「轻一头」。
latin 分片 22KB（与 700 同量级），代价极小。`fonts.css` 加 import、`vendor-fonts.sh` 字重清单同步。

**顺带修正 `vendor-fonts.sh` 输出路径**：`OUT` 原为 `$ROOT/fonts`（项目根），与实际使用目录
`public/fonts`（`css/fonts.css` 以 `../fonts/` 引用）不符——跑脚本会把产物丢进没人读的目录。

## 六、第二轮：声明带可关闭 + 去售价 + 期号从第一期起（同日 11:00–11:10）

### 6.1 读者须知可关闭（用户：允许关闭，5 秒倒计时自己关闭）

**约束**：本站对外承诺「零脚本静态页面」（colophon 明写），不为一个关闭按钮破例。

**实现（全程零 JS，`EditionNotice.astro` + CSS §3c）**：
- **手动**：右上角 × 是个 `<label for>`，切换一个视觉隐藏但可聚焦的 `<input type="checkbox">`，
  由 `.edition-notice-off:checked ~ .edition-notice-clip { display: none }` 收起；
  `:focus-visible` 时给 × 加虚线焦点环（键盘可达）。
- **自动**：5 秒后 CSS 动画把外层 `.edition-notice-slot` 的 `grid-template-rows` 由 `1fr` 收到 `0fr`，
  内层 `overflow: hidden` 完成塌陷。
  **为什么走 grid 行高**：`height: auto → 0` 不可插值；`display` 的离散动画旧浏览器不可靠；
  grid 行高是唯一「既能插值、又能把高度真正收掉」的免脚本路径。
- **倒计时可见化**：底边 2px 红线是进度条（`width: 100% → 0`，与外层同 5s／同延迟），
  让「会自己消失」可预期——否则内容凭空消失会像 bug。

**实测**（agent-browser 逐时刻量测）：

| 时刻 | slot 高 | 进度条宽 |
|---|---|---|
| T+0.3s | 145px | 851px |
| T+3.3s | 145px | 106px |
| T+6.9s | **0** | 0 |
| 手动点 × 后 | **0**（clip 为 `display: none`） | 0 |

**已知取舍**：收起后本次访问内无法再展开（CSS 动画的 forwards 状态改不回来，纯 CSS 也无「记住已读」）。
要「可重开／跨次记住」就必须引入 JS，届时 colophon 的「零脚本」表述须同步改。
另需注意：**这条声明是内容诚信的一部分**，自动消失有代价（读者可能没读完），进度条是对可知性的缓解。

无障碍：属 WCAG 2.2.2「自动消失内容」，已提供关闭钮与可见倒计时条；两者为指示性而非运动性动画，
不触发前庭不适，故不另设 `prefers-reduced-motion` 特例（理由已写进 CSS 注释）。
打印态停用动画并隐藏关闭钮／进度条。

### 6.2 删除「零售价 贰角」

`Masthead.astro` 删 `<p class="issue-price">`，`i18n.mjs` 删 `price` 键（zh/en）。

### 6.3 期号改为「从第一期起算」

**旧口径**：`ISSUE_EPOCH = Date.UTC(2025, 6, 14)`（虚构创刊日），`(date - epoch)/864e5 + 1`——
最初是为了让 2026-09-14 恰好等于第 428 期以对齐 M1 原型版面。
它算的是**日历天数差**而非出刊期数：缺期会跳号，且与站上实际期数无关（站上只有一期却显示 429）。

**新口径**（第一期 = 1，以磁盘上实际出刊序列为准）：
- 渲染层 `src/lib/issues.mjs` 新增 `issueNumberOf(date)` = `dates.length - indexOf(date)`；
- 生成层 `scripts/generate-issue.mjs` 的 `issueNo()` 改为扫 `issues/` 目录排序取位次，
  **两处必须同口径**（已在两边注释互相标明），否则报头与过刊页会不一致；
- 消费方改用派生值而非数据字段：`FrontPage.astro`（报头／印章／版尾）、
  `archive.astro` / `en/archive.astro`（列表行）；
- `issues/2026-09-15.json` 的 `issue` 字段同步 429 → 1，印章（`seal-issue`）随之显示「第〇〇〇一期 / No. 1」。

**验证**：6 页产物期号全部为「第〇〇〇一期」/「No. 1」，印章同步，售价无残留。
